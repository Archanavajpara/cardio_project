To run the CardioPulse AI project, you need to start both the backend and the frontend in separate terminal windows.

### 1. Run the Backend (FastAPI)
Open a terminal, navigate to the `cardio_project` directory, and run:

```bash
# Install required Python dependencies
pip install -r requirements.txt

# Start the FastAPI server (runs on http://127.0.0.1:8000)
python api/index.py
```

### 2. Run the Frontend (React Vite)
Open a new terminal window, navigate to the `cardio_project` directory, and run:

```bash
# Install Node modules
npm install

# Start the Vite development server (usually runs on http://localhost:5173 or 3000)
npm run dev
```

Note: The README mentions `python run.py`, but that file doesn't exist in the project, so you can use the commands above to manually start both servers.
