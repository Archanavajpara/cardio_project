# ❤️ CardioPulse AI - Cardiovascular Risk Predictor & Clinical Intelligence Suite

CardioPulse AI is an enterprise-grade Clinical Risk Assessment & Screening Platform powered by a calibrated **Gradient Boosting Classifier** machine learning model.

---

## 🚀 Quick Start

To launch both the **FastAPI Backend (Port 8000)** and **React Vite Frontend (Port 3000)** together:

```bash
python run.py
```

This single command automatically bootstraps both servers and launches `http://localhost:3000` in your default browser.

## 📊 Features & Clinical Tools

- **Quick Patient Presets**: One-click archetypes (Healthy Young Adult, Hypertensive Smoker, Average Middle-Aged, High-Risk Senior).
- **Live Hemodynamic Biomarker Computing**: Real-time BMI, AHA Blood Pressure Stage classification, Mean Arterial Pressure (MAP).
- **Interactive Risk Gauge Chart**: Radial risk probability visualization with calibrated threshold bands.
- **Biometric Polar / Radar Chart**: Compares 6 key patient dimensions against optimal clinical targets.
- **Risk Factor Breakdown & Action Plan**: Automated extraction of risk flags and tailored lifestyle recommendations.
- **Clinical Summary Dossier Export**: Formatted printable/downloadable `.txt` assessment summary reports.
- **Offline Resilient Mode**: Seamless offline inference fallback if the server is starting.
